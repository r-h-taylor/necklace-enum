Necklace Enum

Necklace Enum lists the symmetrically distinct derivative superstructures of a parent lattice — the ways of decorating it with several kinds of atom — by generating each one directly instead of filtering out duplicates. Reading the sites of a superlattice column by column along the largest cyclic factor of its quotient group turns every decoration into a word on which translations act as rotations, so the distinct structures are Lyndon words and can be produced with a necklace algorithm. The Python package reproduces all published counts and is one to two orders of magnitude faster than earlier codes.

  • Download the package — GitHub — DOI

  • Unzip the download, open a terminal in the folder and run pip install . (Python 3.10 or later; NumPy and Numba are installed automatically). Running python check_necklace_enum.py then checks the installation against the published counts and an independent brute-force code, and times it against the Hart–Forcade algorithm. In Python:

    import necklace_enum as te

P = te.fcc(["Cu", "Au"])

# number of structures for each cell size
te.count_structures(P, range(1, 13))

# every Cu6Au2 structure with 8 atoms per cell, as ASE Atoms
for s in te.enumerate_structures(P, 8, composition={"Cu": 6, "Au": 2}):
    atoms = s.to_ase()

    Other parents are te.bcc, te.sc and te.hcp, or te.Parent for any lattice and basis, with optional site restrictions. Exporting to ASE needs pip install ase. The README describes all options and the necklace-enum command-line tool.
